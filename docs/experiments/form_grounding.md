- VLM grounding은 깨끗한 서식을 나눠 물으면 칸은 대부분 찾지만 엉뚱한 상자가 절반 넘게 섞이고, 사진에서는 같은 칸을 반복 출력하며 무너짐. 한 장에 1.5~3분이라 사용자가 기다리는 기능에 쓰기 어려움.
- 서식을 미리 알고 있으면(빈 서식 PDF가 있으면) 사진을 빈 서식에 겹치는 방법이 정확·빠름. 단 등록된 서식만 됨.
