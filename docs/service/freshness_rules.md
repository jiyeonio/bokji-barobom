# 영상 정보 최신성 경고 — 비교 규칙

장면 자막의 수치가 공공데이터 현재 값과 다르면 「영상 속 정보는 OOOO년 기준이에요. 현재는 OOO이에요(출처·기준일)」를 검색 결과 장면 카드와 시청 화면에 보여 줍니다. 코드: [backend/services/freshness.py](../../backend/services/freshness.py).

**원칙: 틀린 경고를 내지 않는 것이 놓치는 것보다 중요합니다.** 그래서 아래 조건을 모두 만족하는 경우만 경고합니다.

## 비교 조건 (2026-11-15)

1. **정책**: 영상이 시연 목록에서 그 정책과 연결돼 있고(`policy_hint` → 정책), 그 정책의 공공데이터에 금액(`amount`)이 있어야 함. 지금 비교하는 정책은 **기초연금**뿐(금액 범위 10만~100만 원).
2. **지급액 문장만**: 자막 한 문장 안에서 금액이 「매달 / 매월 / 월 / 월 최대」 바로 뒤에 나와야 함(예: 「매달 25만 원씩」). 금액만 따로 나온 문장은 비교하지 않음.
3. **다른 돈 이야기 제외**: 같은 문장에 접수비·신청비·수수료·요금·감면·보증금·월세·이체·환급·대출·비용·부담금이 있으면 비교하지 않음.
4. **차이**: 영상 금액이 공공데이터 현재 값(기초연금: 단독가구 최고 349,700원, 부부가구 최고 559,520원) 어느 것과도 1,000원 넘게 다를 때만.
5. **표시 범위**: 검색 결과에서는 찾은 장면 구간(앞뒤 2초)과 겹치는 경고만, 시청 화면에서는 그 영상의 경고 전체(재생 위치가 경고 문장 근처면 강조).

## 아직 하지 않는 것

- **화면 글자(OCR)**: 읽기 오류로 틀린 경고가 날 수 있어 비교하지 않음.
- **나이·기간**: 「만 65세」처럼 바뀌지 않은 값이 대부분이고, 기간은 문장 형태가 다양해 오탐 위험이 커서 아직 비교하지 않음.
- 다른 정책으로 넓힐 때는 정책별로 금액 범위와 문장 규칙을 이 문서에 먼저 적고, 시연 영상 전체에서 경고 목록을 확인한 뒤 켭니다.
